# 🎓 GESTION DES ÉTUDIANTS

## 📌 Présentation du projet

**Gestion des étudiants** est un projet développé en langage C ayant pour objectif de faciliter l'enregistrement, le suivi et la gestion des informations académiques des étudiants.

Le projet est organisé en deux versions complémentaires :

## 📂 Organisation du projet

### 1. Gestion_EtudiantV1 — Version 1.0 (Console)

Première version du projet, développée en langage C avec une interface en ligne de commande.

Elle permet notamment :
- D'ajouter, modifier, supprimer et rechercher des étudiants.
- De gérer les notes et les moyennes.
- De consulter les résultats et les statistiques.
- D'enregistrer, charger et sauvegarder les données.

### 2. Gestion_EtudiantInterface — Version 2.0 (Interface graphique)

Deuxième version du projet, qui vise à faire évoluer l'application console vers une interface graphique moderne et intuitive.

Elle aura pour objectif de faciliter les interactions avec l'application grâce à des fenêtres, des formulaires et des tableaux de gestion.

## 🎯 Objectifs du projet

- Mettre en pratique les concepts fondamentaux du langage C.
- Améliorer progressivement l'organisation et la structure du code.
- Faire évoluer une application console vers une application graphique.
- Développer une solution de gestion des étudiants plus complète.
