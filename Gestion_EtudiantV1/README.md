# 🎓 Gestion_Etudiant V1

**Application console de gestion des étudiants développée en langage C.**

## 📌 Présentation du projet

**Gestion_Etudiant V1** est une application console permettant de gérer les informations des étudiants et leurs résultats académiques.

Le projet a été réalisé en langage C dans le but de mettre en pratique plusieurs notions fondamentales de programmation, notamment les structures, les tableaux, les pointeurs, les fonctions et la gestion des fichiers.

Cette première version propose une interface textuelle simple permettant à l'utilisateur d'effectuer différentes opérations à travers un menu interactif.

## ⚙️ Fonctionnalités

- Ajouter un étudiant.
- Afficher la liste des étudiants.
- Rechercher un étudiant.
- Modifier les informations d'un étudiant.
- Supprimer un étudiant.
- Trier les étudiants selon différents critères.
- Consulter les résultats académiques.
- Afficher les étudiants admis et non admis.
- Générer un bulletin individuel.
- Identifier les mentions des étudiants.
- Afficher un tableau de bord statistique.
- Enregistrer et charger les données.
- Créer et restaurer des sauvegardes (Backup).

| Technologie | Utilisation |

## 📚 Notions de programmation utilisées

Ce projet permet de mettre en pratique :

- **Structures (`struct`)** : organisation des informations des étudiants.
- **Tableaux** : stockage de plusieurs étudiants et de leurs notes.
- **Pointeurs** : manipulation des données et passage par adresse.
- **Fonctions** : organisation et réutilisation du code.
- **Fichiers** : enregistrement et lecture des données.
- **Tri et recherche** : organisation et recherche des étudiants.
- **Gestion de la mémoire** : manipulation des données en C.

## 🚀 Installation et exécution

### 1. Cloner le projet

```bash
git clone https://github.com/TON-UTILISATEUR/Gestion_Etudiant.git
```

### 2. Accéder au dossier

```bash
cd Gestion_Etudiant
```

### 3. Compiler le programme

```bash
gcc main.c -o GestionEtudiant
```

### 4. Exécuter l'application

```bash
./GestionEtudiant
```
